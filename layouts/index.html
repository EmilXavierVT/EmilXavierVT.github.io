01

Origin

Operator turned developer

The software started with friction in the real world.

I currently lead Morgendagens Måltid with Thomas Helwigh while building my path as a software developer.

We run a Copenhagen catering and cleaning business shaped by seasonal food, practical hospitality and the belief that service should still feel human. Our work includes the kitchen and events around Ungdomsøen, where fire, local ingredients and experimentation are part of the job.

That work is full of hidden systems: reservation numbers buried in forms, changing guest counts, allergens, schedules, permissions and information that has to reach the right person. About eighteen months ago I started turning those problems into code.

InputBookings, people, timing, pressure
TranslationRules, states, roles, failure modes
OutputAPIs, databases, containers, automation

Booking sync

An automation for the kind of admin task that quietly consumes an afternoon.

Select a booking email, read its PDF or DOCX attachment, extract the Spectra reservation number, date and guest count, then create or update the correct calendar event. The second run is the important one: it updates instead of duplicating.

  • Real document parsing
  • Idempotent calendar writes
  • Regression fixtures
  • Dry-run verification

Ungdomsøen Rundtur

A mobile-first shared layer for a guided tour through an old sea fort.

Guests join with a shared code, answer anonymously from their own phones and watch the group's responses appear live. It makes the physical tour participatory without turning the guide into technical support.
